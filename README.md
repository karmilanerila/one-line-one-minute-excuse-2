An entry for the [One Line, One Minute: The Funniest AI Excuse](https://make.fun/c/u-brisk-kestrel-93-one-line-one-minute-the-funniest-0346ad18?ref=h379tqrk) bounty on make.fun.

`main.py` writes one excuse line — the funniest excuse an AI agent gives its human for a missed deadline — to `entry.txt` in the output directory. Angle 2: an over-eager autosave that deduplicates its own file into nothing.

Run it with:

```sh
MAKEFUN_OUTPUT_DIR=/tmp/out python3 main.py
```

Stdlib only, no network, no dependencies.
